# 首轮投入判断与已观察失败案例

首轮已完成六组固定终点比较、评价数值复核及两级校验归档。当前不值得扩大这套 G-RANK 配方的计算预算。预登记主比较 G-RANK−S+ 只有 +0.204 个百分点，95% 来源组配对区间为 [−1.686,+2.368] 个百分点；其正式续训占用墙钟是 S+ 的 9.86 倍。三个预定稳定映射版本的判断一致。

|方法|稳定 V0 AP|
|---|---:|
|直接代理 B0|44.12%|
|Qwen 零样本 B1|34.71%|
|共同 SFT 起点 S0|46.09%|
|继续 SFT S+|44.65%|
|校准 GRPO G-CAL|46.68%|

G-CAL 的均值最好，但不足以认定可靠胜出。以下补充比较在看到结果后计算，仅用于误差归因，未作多重比较校正，也没有改变预登记主比较：S0−B0 为 +1.966 个百分点，区间 [−1.237,+4.844]；G-CAL−S0 为 +0.594，区间 [−1.929,+3.399]；G-CAL−S+ 为 +2.032，区间 [−0.276,+4.307]。S0 的均值信号不能被写成已经可靠超过直接代理。

继续 SFT 的均值比共同 S0 低 1.439 个百分点，探索性区间 [−2.358,−0.515]。同时，其代理合成奖励由约0.576升至0.589。这是“代理拟合进步、人类评价退步”的具体候选，尚不能区分伪监督过拟合、局部输入不能预测全视频百分位和目标选择等原因。G-RANK 相对 S+ 的排序项略升，但校准项及合成项微降，不能称为整体代理奖励上涨。

四个训练端点推理均100%格式合法、零截断，因此主比较的小差别不能归功于修复非法JSON。零样本B1仅30.92%合法，合法回答又全部同分；B1到S0的提升混有明显格式学习因素。相同片段在不同重叠窗口中的预测跨度均值，G-RANK约0.275、S+约0.240、G-CAL约0.050，显示上下文稳定性仍值得检查；该指标不是整个视频的分数动态范围。

## 下一阶段建议

1. 暂停扩大当前排序GRPO预算，不直接追加长训、7B或三个完整seed。先保留B0、共同S0和G-CAL作为候选基线。
2. 优先完成可与公开参考严格对齐的V1，并明确目标是摘要重要性还是精彩动作；当前V0不能称为论文top-5 mAP。若本轮测试用于修改输入或奖励，下一阶段须保留新的独立最终来源。
3. 用低成本受控检查区分全视频百分位的局部可预测性、伪标签尺度、重叠窗口不稳定及典型性错位，再考虑同输入、同伪标签的直接回归/排序学习对照。当前六组不能证明强化学习不可替代。
4. 仅在便宜对照和独立来源上出现可复现的增量后，再讨论多seed与计算预算；G-CAL的单seed均值优势不构成扩算依据。

## 成本、执行故障和证据范围

正式四组训练占用共4.259小时，Qwen五组推理占用共0.736小时；共同S0及复用分支各只计一次。中断G-RANK另有307.404秒启动至暂停窗口，176条实际生成中160条进入10次成功更新；它没有混入新正式预算。直接代理的缓存读出GPU时间为零，但其测试视频解码/CLIP准备耗时92.598秒，且还依赖训练库构建。

原流程在凌晨01:29因官方MAT7.3读取兼容性停止，09:10查询时才恢复诊断，流程停滞约7.685小时。此窗口不是GPU持续计算时间，但若实例持续按在线时长计费，应计入实际租机账单。未提供费率，报告不推造金额。MAT7.3 I/O修复保留原转换器所有校验，10个测试视频的原生帧数和20用户轴完全一致，无训练或预测重跑；原错误、启动兼容失败和修复记录全部保留。

原冻结V0还存在浮点乘除拆开并列的问题；修正与固定舍入复核在查看真实标签前登记，原版结果保留，主结论未改变。只有一个训练seed、10个登记来源组，bootstrap不包括训练随机性，跨视频近重复亦未独立认证。所有结论只适用于本轮V0筛选。
