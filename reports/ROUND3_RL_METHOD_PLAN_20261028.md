# 第三轮无监督高光检测强化学习方法实验方案

日期：2026 年 10 月 28 日，香港时间。状态：设计完成，尚未实现或执行。本方案由用户转交执行 agent 后作为执行依据，阶段之间按预定规则推进，不反复索取确认。

研究主线固定为 Qwen 加 GRPO。两个候选贡献是事件语义辅助的可靠伪监督，以及利用可靠程度控制学习信号的排序奖励与 GRPO 更新。下一轮必须交付新的方法实现、实际训练端点和明确的路线判断；若前端明显不合格，立即交付具体失败证据，停止消耗后续训练预算。

本轮不是再开展一批独立诊断。评价、教师和奖励检查均有时间上限；只允许一个预先定义的教师回退版本。正式训练后不改目标、不扫描超参数、不挑最好 checkpoint、不追加长训。

## 本轮目标与边界

主假设：相较于精确拟合视觉重复性百分位，以视频事件证据修正伪目标，并对不可靠的奖励降低更新强度，能够提高 GRPO 的人工重要性排序表现。

需要区分三个结论：教师改进是否成立、奖励与更新改进是否成立、完整方法是否有继续正式 benchmark 的价值。不能只靠总奖励上涨或一个最好的 seed 回答这些问题。

| 固定事项 | 规定 |
|---|---|
| 模型 | 本地 Qwen3-VL-2B-Instruct，沿用已核验 revision；不增加 7B 或付费教师 |
| 策略起点 | 原实际 BF16 合并共同 S0，所有新训练从同一权重开始 |
| 策略输入 | 保持原 2 秒片段、每片段 4 帧、8 片段窗口、stride 4、16 格全视频概览 |

## B 事件语义辅助的伪监督

### 教师接口

T0 保留原 R0 全视频百分位 `q0`，可靠权重统一为 1。T1 输出同样长度的 `q1` 及权重 `c1`，二者均在 0 至 1 内。q 是训练目标分数，c 是启发式可靠权重，均不声称是校准概率。

每条片段记录至少包含 video_id、clip_id、实际时间边界、q0、q_excl、两次语义分数、语义分歧、q1、c1、教师与帧来源哈希、回退原因。教师分数和权重不进入策略 prompt；所有方法的策略输入保持一致。

### 重复性参照

复用冻结的 CLIP、UMAP 和簇分配。训练视频计算 `q_excl` 时，只从所属簇原型中排除该视频全部片段，不重新聚类；其余计算与原 R0 保持相同。开发或独立视频仅使用训练视频库。

若排除后簇为空，回退至其余全部训练视频的原型，仍排除自身；该回退必须记录。训练视频仍参与最初聚类，因此不能把它称为完整交叉拟合。

单独输出 q_excl 的直接评分结果用于解释教师变化，不额外训练 LOO 小模型。T1 是“参照修正加语义修正”的整体模块，本轮不声称已分别证明其两个内部成分的因果贡献。

### 冻结语义教师

使用本地原始 Qwen3-VL-2B-Instruct，冻结全部参数，不使用正在更新的策略作教师。先用既有全视频概览为每个视频生成最多 6 个可见事件的共同参照，最多 256 个生成 token。禁止输入人工标题、类别、高光分数或之前的失败案例描述。

对每个视频按时间顺序建立不重叠的评分包，每包最多 8 个片段；末尾不足 8 个时按实际数量评分，不补齐、不重复。每个片段在每种表述下恰好获得一个整数分数。每包使用缓存的每片段 4 帧、同一概览和共同事件参照。时间与片段 ID 必须显式绑定，不能把多个片段误当连续新视频。

每包固定做两次语义评分，帧、片段、概览和事件参照完全相同，区别仅为下列两个事先固定的任务表述。两次均 greedy，最多 384 个生成 token，不要求长推理过程。

评分尺度固定：0 为背景、过渡或与核心事件无关；1 为有限的背景交代；2 为相关过程；3 为重要步骤或关键事件；4 为关键结果、决定性变化或核心展示。静态产品与结果展示可以重要，运动幅度大并不自动重要。只依据实际可见信息；不能凭一般常识断言未出现的动作。

表述 A：根据共同事件参照，判断每个片段对理解这条视频核心事件的重要程度。

表述 B：根据共同事件参照，判断缺少每个片段会让观众损失多少关键事件信息。这只是另一种判断表述，没有实际执行删除片段的因果实验。

输出固定为 `scores`、`event_ids` 和 `roles` 三个等长数组，长度等于本包片段数。scores 为 0 至 4 整数；event_ids 必须引用共同参照或为空，其中 scores 为 3 或 4 的片段必须引用至少一个事件；roles 只取 background、context、process、key_action、result、uncertain。事件引用只能验证格式与参照关系，不能自动证明画面证据正确。教师自报 confidence 不作为训练权重。

设两次分数为 a、b：

- `u=(a+b)/8`。
- 若两次合法且差值为 0，`z=1`；差值为 1，`z=0.75`；差值超过 1、任一 uncertain、格式错误或非法事件引用，`z=0`。
- `q1=(1-alpha*z)*q_excl + alpha*z*u`。
- `c1=0.25+0.75*z`；z=0 时 q1 自动退回 q_excl。

首版固定 `alpha=0.75`。q1 不再次做百分位变换，避免人为强迫每条视频产生固定比例的高光。均值、方差、并列比例和覆盖率均报告。两次同源模型判断一致仅表示稳定，不证明标签正确，必须经过下面的开发质量检查。

共同事件参照若非法，相关视频保留 q_excl、c1=0.25，不额外请求在线大模型补救。原零样本 B1 曾有严重格式问题，所以先在按 ID 确定的 8 个训练视频、共 16 次片段评分上检查格式；这批调用计入总缓存。合法率不足 95% 时只允许一次 JSON 格式实现修复，不能根据人工标签改提示。

### 教师一次性准入检查

先冻结全部 q/c，再读取开发标签。偏好质量按每个视频中至多 2,000 个由固定 seed=310 固定抽取的无序片段对计算；对新教师 `c>=0.75` 且 `|q_i-q_j|>=0.15` 的片段对，比较预测方向与 20 用户平均重要性方向，人类同分记半分。先在视频内平均，再平均视频。

原教师在完全相同的被选片段对上比较，避免用不同难度的样本得出“教师改进”。同时报告所有预选片段对上的质量以及保留比例。

以下是项目投入门槛，不是统计显著性标准：

1. 新教师高置信片段对一致率至少 60%，且比原教师在同一批片段对上高至少 3 个百分点。
2. 高置信片段覆盖至少 30%，开发集至少 8/10 个视频有可用偏好；原训练池至少 50% 的窗口有 3 对以上可用偏好。
3. 新教师直接评分的主开发指标不低于原教师超过 1 个百分点；V0 同样不得下降超过 1 个百分点。

首版未通过时，只允许固定回退 `alpha=0.50`，复用相同语义缓存重新计算 q/c，不增加教师调用、不改提示、不改阈值。首版通过就直接采用，不计算回退版来挑高分。回退版也未通过则停止正式 GRPO，决定为 `TEACHER_NOT_READY`，给出究竟是偏好质量、覆盖率还是整体排序失败。

准入只排除明显不适合当前训练的信号，不证明伪标签已经“保证正确”。若质量平均提升只来自少数视频，也必须在逐视频表中呈现。

## C 排序奖励与利用可靠程度的 GRPO

### 原模块 R0

沿用原 G-RANK：0.8 原排序项加 0.2 原 MSE 校准项，以及原组内 sample std 标准化。输入由 T0 或 T1 提供的 q；R0 忽略 c。不要把 G-CAL 当成这个因子基线。

### 新模块 R1

策略分数先除以 100 得到 s。在同一个窗口中，选择 `c_i,c_j>=0.5` 且 `|q_i-q_j|>=0.15` 的片段对。权重定义为：

`w_ij = c_i*c_j*abs(q_i-q_j)*(1+max(q_i,q_j))`。

方向正确得 1，策略同分得 0.5，方向错误得 0。按 w 归一化得到 `R_pair`。这个权重对教师更重视的片段加强排序约束，但它不是人工 AP 的无偏估计，也不是数学上保证优化 AP。

为提供跨窗口共享的粗粒度分数参照，使用全视频 q 定义高低锚点：`H={q>=0.8,c>=0.5}`，`L={q<=0.2,c>=0.5}`。窗口内存在 H 时计算按 c 加权的 mean(s)，存在 L 时计算按 c 加权的 mean(1-s)；对存在的两类等权平均，得到 `R_anchor`。

有效时 `R=0.8*R_pair+0.2*R_anchor`。只有一项有定义时使用该项；两项均无定义时该组不提供策略或 KL 更新。锚点刻度来自整条视频，不按当前窗口重新选最高与最低。恒定 50 分的两个分量均为 0.5，不会因均值回归自动得到接近 1 的奖励。

非法 JSON 或越界输出奖励为 -1，保留原处理；合法输出没有额外格式奖金。信息缺失组的格式失败照样记录，但不据此制造训练信号。

组可靠权重 `u_g` 为参与任一有效奖励项的不同片段的 c 均值。对 G=4 个回答，计算组均值和 sample std：

`A_i = u_g * (R_i - mean(R)) / (max(std_sample(R),0.05)+0.0001)`。

KL 项也乘同一个 u_g，beta 保持 0.04；批次仍按原固定样本数归一化，不除以权重和。这样不会因为仅缩小整个组的原始 reward 而被组内标准化抵消。0.05 是此次固定的奖励标准差下限，不进行扫描。R1 包括奖励与更新两部分，结果不能声称已经把二者单独归因。

优势与权重全部 detached。u_g 来自冻结教师，不由策略自己报告。没有有效证据的组 u_g=0，策略损失和 KL 损失都为零；账本仍保留生成、消费和零信号记录，不能当作有效学习更新。

### 有限技术检查

先做 CPU 检查：排序全对、全反、恒分、只改变分数尺度、在同等置信度与差值下交换高分或低分片段、低置信片段、无有效偏好、非法输出，以及整体降低 u_g 后的真实损失权重。必须核对原 R0 未被意外修改。

再固定 32 个训练提示，每个生成 G=4 个回答，不看人工标签。至少 25% 的组应有非零内容奖励方差；若不足，记 `REWARD_NO_SIGNAL`，不自动提高温度、G 或延长训练。进行 4 步真实更新，核对非零梯度、参数变化、固定 reference、实际优势和实际损失。任何失败只能修一次明确的代码错误。

不得只在日志中记录“新的优势”，实际 trainer 仍使用旧优势；必须从损失计算路径复算其贡献。无需重复首轮已经完成的全部环境审计，只检查本次改动涉及的路径。

## D 固定方法矩阵

| ID | 教师 | 奖励与更新 | 作用 |
|---|---|---|---|
| E00 | T0 | R0 | 同预算的当前路线基线 |
| E10 | T1 | R0 | 教师整体模块的贡献 |
| E01 | T0 | R1 | 新奖励与更新模块的贡献 |
| E11 | T1 | R1 | 完整候选方法 |
| S1 | T1 | 加权 SFT | 使用新伪监督的直接学习对照 |

四组 GRPO 固定 128 步，每步 4 个提示、每提示 4 个回答，每组共 512 提示曝光、2,048 个生成回答。S1 为 128 步，每步 4 个提示、共 512 曝光，不做额外生成。

全部沿用同一个训练提示池、同一数据顺序和输入张量。teacher 不改变窗口采样分布；低置信度通过奖励和权重起作用，不暗中给 E11 换更容易的数据。LoRA rank=16、alpha=32、dropout=0，语言线性层可训；视觉与 aligner 冻结。lr=1e-5、cosine、warmup=0.05、gradient clip=1，其余沿用已核验配置。G=4、temperature=1、top_p=1、num_iterations=1、beta=0.04、clip epsilon=0.2、completion cap=128。

S1 的目标为 `rint(100*q1)`。数值 token 的 CE 按对应片段 `c_i*(1+q_i)` 加权，JSON 结构 token 权重为 0.1；每序列按实际 token 权重和归一化。必须核对 tokenizer 的数值跨度，不能把 prompt token 纳入 loss。S1 获得同样的 q/c，但优化目标不同；它是新伪监督的直接学习基线，不声称所有训练信息利用方式完全等价。

只用 128 步作为主端点。保存 64 和 128 步；只有 seed 42 的 E11、S1 额外评价 64 步，且在五个 128 步端点预测冻结之后统一查看，用于判断后半程是否退化，不据此选模型。所有继续训练均新建 adapter，不修改共同 S0。

首轮 256 步 G-CAL、G-RANK 作为历史参照，不能替代 E00 的 128 步匹配基线。旧预测仅在输入和映射一致时复用。所有生成失败仍进入完整评价，不丢弃不利窗口。

## E 一次扩展判断

完成 seed 42 五分支后只作一次决策。M 表示 A 阶段事先选定的主指标，单位为百分点。

继续至重复训练需同时满足：

1. E11 的 M 比 E00、E10、E01、S1、S0、既有 G-CAL 和直接 T1 中的最高值至少高 2 个百分点。
2. E11 的 V0 不低于这些参照中最高 V0 超过 1 个百分点。
3. E11 相对 M 最强参照，在至少 6/10 个开发视频上有正增益。
4. 没有依赖删除非法回答、单纯修复格式或改变评价口径获取提升。

这些是本项目的扩算门槛，不是普遍适用的统计显著性标准。小于门槛的结果可以报告为微弱信号，但不追加训练追分。

通过后，从 E00、E10、E01 中按 seed 42 的 M 选出最强 GRPO 对照 C；并列按 E10、E01、E00 固定顺序选择。追加 seed 43、44 的 E11、C、S1，各保持同样 128 步预算。数据顺序固定、采样和新 adapter 初始化 seed 改变。

最多 8 个 GRPO 训练和 3 个 SFT 训练。共同 S0 只用一个原 seed，所以这里衡量的是续训随机性，不是从基础模型开始的全流程三 seed。种子 42 选择 C 引入开发选择效应，必须披露。

三 seed 后，E11 相对 C 与 S1 的平均 M 均至少高 1 个百分点，且至少 2/3 个 seed 为正，才认为有可重复的内部 RL 方法信号。报告每个 seed、逐视频差异、来源组配对 bootstrap 区间及 seed 标准差；不能把窗口或三个 seed 下重复出现的视频当作独立样本。

E10-E00、E01-E00、E11-E10、E11-E01 和交互差 `(E11-E10)-(E01-E00)` 必须全部报告。没有重复的消融只能写单 seed 证据，不能宣布两项贡献均已充分验证。

## G 独立数据筛查与竞争力

A 阶段就以公开 YouTube Highlights 原始划分确定独立筛查名单，在查看其人工高光标签之前冻结。按官方六类别分别对可用原始视频 ID 做固定哈希排序，每类取 4 个官方测试视频，共 24 个；类别只用于覆盖抽样和报告，不作为模型输入。不能只用特征文件代替 Qwen 所需原视频。

下载和可用性检查最长 1 小时主动工作、原始资产新增最多 10 GiB；保留缺失与替换日志，替换只能按预定哈希后续顺序、依据文件可用性进行。检查与 TVSum 的源 ID 和可识别重复，冻结后不挑视频。如果不足 24 个或缺类别，标记外部筛查未就绪，不改用挑选的好例子。

只有 E 阶段的三 seed 结果通过后才执行外部推理。固定用 seed 42 的 E11、S1 和 S0，不挑最佳 seed；三种完整预测冻结后一次性读取外部人工标签。沿用本轮推理与聚合规则，不用外部标签选 prompt、锚点、温度或端点，不在这些视频上训练。

这一步是 TVSum 训练后向 YouTube 的迁移筛查，采用官方可核验的 YouTube mAP 定义并报告逐类别与逐来源结果。E11 同时优于 S1、S0，且相对 S0 至少 4/6 类为正，作为继续正式多数据集评测的方向性支持；必须同时给出区间，不能将 24 个视频写成完整 benchmark。

公开参照表至少包含：CHD 的 TVSum 52.76 / YouTube 65.39；UAVR 的 60.34 / 68.30；使用外部 ActivityNet 预训练的 MT/RASL 的 78.30 / 65.10。分别记录视觉、视听、外部训练视频和预训练模型知识。它们是文献值，不是本项目复现值，也不是同一开发划分的门槛。

完整五次 TVSum 划分和完整 YouTube 测试属于方法冻结后的正式验证工作，不计入本轮 12 小时，也不自动启动。不能把现有 S0 换一个 TVSum 划分后继续当无泄漏模型：新划分的测试视频可能已经用于训练该 S0，必须按各划分重建训练流程。

## 最终路线判断

| 观察到的结果 | 本轮结论与处理 |
|---|---|
| T1 两个预定混合系数都无法通过准入 | 当前语义教师构造不可用，停止 GRPO，交付教师代码、缓存和质量失败表；不再做第三个 prompt |
| 教师通过，但 R1 无有效信号或实际优势错误 | 奖励或更新实现未就绪；完成一次明确修复仍失败就结束，不长训 |
| E10 改善，而 E11 没有超过 E10 | 教师有信号，新奖励没有显示额外收益；不能宣布第二项创新成立 |
| E01 改善，而 E11 没有超过 E01 | 新教师没有提供额外收益，检查记录中的质量/覆盖即可，不另开消融网 |
| E11 改善，但 S1 同样好或更好 | 新监督信息有用，GRPO 额外收益尚未成立；保留 RL 主线，结束当前配方 |
| 64 步较好、128 步下降且训练奖励继续升高 | 记录续训退化；不改选 64 步冒充主结果，也不再延长训练 |
| seed 42 达标，后续 seed 不稳定 | 单次开发增益不可重复，结束当前配方，不再补 seed 挑成功 |
| 内部重复通过，外部结果不支持 | 有内部方法信号但迁移未成立，不宣称竞争力；不在外部集上再调参 |
| 内部重复与独立筛查均支持 | 冻结当前方法，准备正式 benchmark；下一阶段仅实施固定方案的完整评价 |
| 预算、数据或协议导致未完成 | 明确写 BUDGET_LIMITED / DATA_NOT_READY / METRIC_NOT_READY，不能推断科学失败 |

一次实验不能保证找出唯一因果原因。应把结论限定到已经隔离的模块：教师、奖励与更新、训练泛化或证据不足。尤其不能把“奖励升高、人工指标下降”直接等同于已证明奖励投机；也不能把 seed 42 的五组结果当成独立验证。

## 执行 agent 的交付要求

首次启动正式训练前交付一页冻结摘要：共同 S0 身份、T1 是否使用回退系数、主指标状态、数据/代码哈希、实际预算估计和独立筛查名单。这个摘要用于记录，不作为再次等待确认的关卡。

运行期间每个阶段完成后汇报产物和下一步；发现异常及时说明剩余预算，不无限自动重试。最终最少交付：

1. `DECISION.md`：一句路线判断、固定矩阵结果、两项候选贡献分别成立到什么程度、明确下一步。
2. `method_spec.json` 与源代码：最终实际执行的参数和输入接口，不能只交想法或诊断脚本。
3. `teacher_quality.csv`、全部 q/c 及语义缓存索引：来源、覆盖率、直接评分、偏好质量和回退记录。
4. `results.csv`、`per_video.csv`、`per_seed.csv`：所有预定端点，不隐藏不利分支；历史结果和新运行分列。
5. 模型 adapter 与实际 rollout/loss 账本：奖励组成、原/实际优势、u_g、KL、有效组比例、生成 token、时间和峰值显存。
6. `external_screen.json`、`resource_receipt.json`、`artifact_index.json`：独立筛查身份与状态、完整资源消耗和文件哈希。

未达到训练准入时，模型项写“未训练及原因”，但教师、奖励实现和失败证据仍须交付。不得把未来文件路径或方案中的预算写成已经发生的事实。
