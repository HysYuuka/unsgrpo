# 完整方法实现记录

主实现位于 `src/croprank/model.py`：OpenAI CLIP ViT-B/16 严格加载全部已使用的视觉层，取 blocks 4/8/12；独立原图长边 1024 的 ImageNet ResNet18 stem/layer1/layer2；语义 256 维、细节 128+128 维。CLIP 的全局图像投影及最终 ln_post 不在本方案逐层 patch 表示路径上，明确不实例化；不是静默忽略缺失权重。

CLIP long edge 512、右下补齐 16，位置嵌入二维插值。每个 patch 均与真实图像有交集；补齐部分的归一化输入为零，跨注意力空间权重按真实单元面积处理。CLIP patch 中心为 8+16q；ResNet 网格中心为 0.5+stride×q，分别换算回原图边界坐标。细节 stride8 对齐到 stride4 使用 q8=q4/2，而不是默认上采样的半像素偏移。

每候选 81 布局 token、64 边界 token、1 评分 token；两次 8 头框内/框外交叉注意力，通道门控，2 层 256 宽 8 头 Transformer。边界用四边正确法线的内/中/外原始样本与有方向差分；越出原图部分置零并携带有效性标志。空 RoD 明确返回零且门控屏蔽。

FULL 91,104,580 参数；MATCHED 91,039,044 参数，差 0.072%。MATCHED 保留全部原始视觉输入和关系网络，不在源 token 加候选坐标，也不附加有方向差分。其输入差异之外的同形状状态在每 seed 精确共享初值。全输入的 linear/conv/mm 计数差 0.072%；框架计数未覆盖 fused attention/逐元素算子，相关 attention 张量形状相同。完整计数证据保存在验收 JSON，不将部分计数伪称完整硬件 FLOPs。

损失与梯度重放见 `core.py`、`replay.py`。全部候选先得到完整评分向量并计算全候选回归、所有 pair 的软排序和选择损失；候选分块 4 重算，完整一阶梯度回传两个视觉分支。新建模块 dropout 为零，恢复 RNG；固定 BN running statistics，训练 affine。仅完成一个原图 batch 后更新 AdamW 和 clip。最后不足 8 个原图的 batch 保留全部原图、按实际数量平均，已在协议中明示。

MUSIQ 使用 pyiqa 0.1.16 的真实底层网络与完整原生多尺度预处理（224/384/原分辨率，原图 patch 上限 -1）。仅隔离导入、严格本地加载及修正训练时原始 RGB 预处理入口；没有冻结特征。评分为 10-bin 分布的 1–10 期望再做 (μ−1)/9。源文件与适配记录均已存档。

数据实际情况在训练前锁定：3,336 个官方记录，其中一对训练图完全相同，形成 2,635/200/500 个独立训练/验证/测试原图。两套原始 MOS 分别计算完整损失后平均，未重写标签。官方 -2 无效标签按作者读取器过滤；6 个低于名义 1 分的原始 MOS 保留，使用固定名义仿射归一化，不 clipping。验证与测试没有重复原图，也未移动任何原图跨划分。

训练启动前已完成全模型 FP32 直接/重放梯度对照、BF16 误差量化、MUSIQ 真反传及其重放等价、物理坐标斜坡与法线检查、候选顺序/重复/分块不变性、参数更新和完整对照初值一致性。小候选只出现在这些软件验收中，正式训练每张原图保留 52–90 个合法候选。

工程优化补充：完成原 chunk=4 的 100 正式步骤测量后，按最大原图与全部 90 候选核验 chunk=90。FP32 全参数相对 L2 3.73e-7、最差有意义张量 1.32e-6，BF16 梯度余弦 0.999994。候选并行数改为 90，原图有效 batch 仍为 8，所有候选、结构、分辨率和损失保持；从已有 optimizer/RNG 断点继续。旧 chunk=4 耗时保留并明确已被新吞吐阶段取代。见 ENGINEERING_RUNTIME.json。

MUSIQ 候选块按 4 进行原生多尺度 token 批处理；仅对较短序列追加 validity=0 的 padding，未截断任何有效 patch。原逐候选与合批的分数误差 1.49e-7、全部 248 参数张量梯度相对 L2 8.96e-6，最差 2.88e-5，见 MUSIQ_BATCH_ACCEPTANCE.json。
